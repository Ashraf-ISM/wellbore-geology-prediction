# Outputs

This directory holds all training artifacts:

| Sub-directory | Contents |
|---|---|
| `models/`  | Serialised model files (`.pkl`, `.pt`, `.cbm`) |
| `plots/`   | Saved figures (feature importance, OOF diagnostics, log curves) |
| `logs/`    | Training log files |

All files in these sub-directories are excluded from version control.
